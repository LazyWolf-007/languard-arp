# LANGuard ARP

LANGuard ARP is a local Computer Networks laboratory for explaining ARP mapping changes, detecting simulated spoofing attempts, and comparing monitoring with simulated enforcement. It does not capture or send packets, change network settings, or block real traffic. All devices and events are generated by the application.

## Requirements

- Python 3.10 or newer
- Node.js 20 or newer and npm
- Windows PowerShell (commands below also work with small path changes on macOS/Linux)

## Run on Windows

Open two PowerShell terminals in the repository directory.

Terminal 1 — backend:

```powershell
cd backend
py -3 -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Terminal 2 — frontend:

```powershell
npm install
npm run dev
```

The frontend uses `VITE_API_URL` when set and otherwise calls `http://localhost:8000`. The backend accepts browser origins at `http://localhost:5173` and `http://127.0.0.1:5173`; if you serve the frontend from another origin, add that exact origin to the CORS allowlist in `backend/app/main.py`.

Open http://localhost:5173. The API docs are at http://127.0.0.1:8000/docs and health status at http://127.0.0.1:8000/api/health.

## Demo guide

1. Click **Run demo scenario**. It submits two labelled normal mappings and one labelled gateway spoof through the same detection engine.
2. Review the critical gateway alert, mapping table, incident timeline, and labelled evaluation counts.
3. Select **Simulated enforcement** and run **Gateway spoof scenario**. The simulator preserves the trusted gateway mapping and records a rejected decision. In monitoring-only mode, a suspicious claim is observed and logged.
4. Use **Generate normal ARP** for a labelled negative scenario. Stop and restart the simulation from the status card to see the processing guard.
5. Export events as JSON from the page header, or evaluation results as CSV/JSON from the evaluation panel.
6. Click the reset icon by the timeline filters to return to the trusted baseline and clear events, alerts, and decisions.
